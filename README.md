# 云来客栈 · 江湖客栈经营记

一款原创的古风 Q 版休闲经营养成小游戏，纯 HTML5 Canvas 制作，单个网页文件就能玩，不需要安装任何东西。

三叔公云游四海，把落霞镇一间破落的「云来客栈」留给了你。招伙计、研发菜品、修客房、挂灯笼、换招牌，把客栈从一星做到五星，最后在「天下客栈评选」里夺魁，挖出三叔公埋在后院槐树下的宝贝。

## 怎么玩

直接用浏览器打开根目录的 `index.html` 即可。也可以在仓库的 Settings → Pages 里开启 GitHub Pages（分支选 `main`，目录选 `/ (root)`），就能用网址在线玩。

- **营业**：每天从辰时开张到戌时打烊。客人进门找桌、点菜、等菜、吃完留钱，伙计会自动干活。
- **亲自帮忙**：点「点菜」气泡、出菜台上的菜、脏桌子、排队客人的茶碗、正在炒菜的灶台都能亲自动手，会消耗精力，精力会慢慢恢复。抓小毛贼、赶地痞、拦吃霸王餐的不花精力。
- **菜谱**：19 道菜可研发，做得越多越熟练、卖得越贵。不同客人口味不同。
- **伙计**：12 位伙计，可培训、打赏、送礼、聊天，好感高了会触发个人小剧情。
- **装修**：桌椅、客房、灯笼、字画、说书台、金字招牌……都会画进场景里。
- **其他**：随机事件、夜间小插曲、昼夜变化（夜里屋外变暗、屋里点灯）、原创背景小曲和音效。

右上角可以暂停、切换「正常 / 加速」、开关音乐；音效开关在 ☰ 系统面板里。进度每晚打烊后自动存到本机浏览器。

## 目录结构

```
index.html        构建好的游戏，直接打开就能玩
build.py          把 src/ 拼成 index.html
src/head.html     标题、字体和全部样式
src/body.html     页面结构（状态栏、画布、按钮、弹窗）
src/js/
  00-util.js      工具函数、本地存储
  01-data.js      菜品、客人、伙计、装修、星级、任务等数据
  02-audio.js     即时合成的音效和背景音乐
  03-icons.js     菜品与界面图标
  04-chars.js     Q 版人物绘制
  05-sim.js       经营模拟（客人、伙计、后厨、结账）
  06-render.js    客栈场景、气泡、特效、昼夜光照
  07-ui.js        状态栏、对话框、各个面板
  08-flow.js      一天的流程、剧情、随机事件、存档
  09-main.js      启动、主循环、点击处理、标题画面
```

## 修改后重新构建

改完 `src/` 里的文件后运行：

```bash
python3 build.py
```

会重新生成根目录的 `index.html`。

## 说明

游戏中的人物、剧情、美术和音乐均为原创，画面全部由代码实时绘制。字体来自 Google Fonts（马善政毛笔楷书、站酷快乐体），无法加载时会自动换成系统字体。
